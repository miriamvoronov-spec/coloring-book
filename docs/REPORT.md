## 2. מה יש באפליקציה

### מסכים

* **פתיחה:** הלוגו מופיע עם ניצוצות. למטה ברכה ומשפט יומי (אפשר להסתיר כל אחד בהגדרות), וכפתור "פתחי את הספרייה".
* **קטגוריות (המסך הראשי):** כרטיסים גדולים. כפתור הבית מוביל לכאן מכל מקום. כאן מופיעות גם הרשימות "חוברות אהובות" ו"חוברות נוכחיות", כפתור "📥 הוספת חוברת" (PDF, תמונות או ‎.colorbook) וכפתור "👭 חברות וקבוצות". אפשר להוסיף קטגוריות, לשנות להן שם ולבחור להן אייקון.
* **ארון ספרים קסום:** לחיצה על קטגוריה פותחת דלתות עץ עם עיטורי זהב, אור וניצוצות, ומאחוריהן המדפים.
* **מדף:** החוברות עומדות על מדפי עץ. לחיצה ארוכה על חוברת פותחת עריכה: שם, צבע כריכה, כיוון דפדוף, מנגינה, אהובה או נוכחית, שיתוף עם חברות, שיתוף כקובץ, מחיקה.
* **פתיחת חוברת:** החוברת נשלפת מהמדף בתלת-ממד, מסתובבת ומתקרבת עם הבזק וניצוצות. הכריכה נפתחת לכפולה.
* **דפדוף:** שני דפים זה לצד זה על כריכת עור, דפי קלף, עובי דפים בצדדים לפי המיקום בחוברת, סימנייה, ודף שמתהפך בתלת-ממד עם צליל נייר אמיתי. צבע הכריכה מופיע רק על החוברת עצמה, לא ברקע. "כל הדפים" פותח רשת של כל העמודים.
* **צביעה:** לחיצה על דף צביעה פותחת אותו לבד, לגובה כל המסך. "חזרה לדפדוף" מחזיר לכפולה.
* **סגירה:** "הבא" בעמוד האחרון סוגר את החוברת ומחזיר אותה למקומה במדף.

### צביעה

* סרגל כלים אנכי אחד, בצד ימין כברירת מחדל. אפשר לגרור אותו לכל צד, והמיקום נשמר.
* כלים: טוש, מחק ודוגם צבע. בהגדרות אפשר להוסיף עיפרון צבעוני, פסטל שעוונים, מברשת רכה, עט דק ומדגש שקוף.
* לעט ולמחק יש גודל נפרד. יש גם סליידר שקיפות.
* כפתור הצד של ה-S Pen: כל עוד הוא לחוץ, הכלי הוא מחק.
* דחיית כף יד: מהרגע שהאפליקציה ראתה S Pen, האצבע רק מזיזה ומגדילה.
* זום בצביטה עד פי 8. הקשה בשתי אצבעות מבטלת.
* ביטול וחזרה של 60 צעדים, כולל פעולות שכבה.
* **"בתוך הקווים"** (כבוי כברירת מחדל): הצבע נשאר באזור שבו התחלת, כולל רוחב הקו, כך שלא נשאר פס לבן.
* **מנורה 💡:** מדגישה את כל האזורים של המספר שבצבע הנוכחי, עם מסגרת זוהרת ופעימה. לחיצה נוספת מכבה.
* **"🎨 צבעי הדף":** המקום היחיד לצבעים. ✏️ משנה צבע (נשמר לדף), 💧 דוגם מהדף, מהרפרנס או מהפתרון.
* **רפרנס:** חלון צף שמקבל PNG, JPG ו-PDF.
* **פתרון:** "הצג פתרון" מניח את דף הפתרון המקורי מעל הדף בשקיפות מתכווננת. "חלונית פתרון" היא חלון צף שאפשר להזיז, להגדיל ולהקטין. אם אין פתרון מקורי, נוצר פתרון אוטומטי ומסומן ככזה.

### שכבות

* שכבות צבע ללא הגבלה: הוספה, שכפול, מחיקה, שינוי שם, הסתרה, נעילה, שקיפות ומצבי מיזוג (רגיל, multiply, overlay), והעלאה והורדה בחצים.
* שכבת קווים ושכבת מספרים שאפשר להסתיר.
* הצבע תמיד מעל הקווים, כך שהציור הגמור נראה כמו תמונת הפתרון.
* שכבה נעולה מוגנת, ועם "בתוך הקווים" הצבע שלה נחשב גבול.
* שמירה אוטומטית. ייצוא דף כ-PNG וחוברת כ-PDF.

### הוספת חוברות

* **PDF:** אשף עם שם, קטגוריה, כיוון ובדיקת סוג כל עמוד (כריכה, צביעה, פתרון). הקריאה רצה ברקע, וההתקדמות מוצגת במסך הקטגוריות. גם קבצים מעל 1GB נפתחים.
* **דפים שצולמו חתוכים:** באשף יש בחירה: להשאיר (ברירת מחדל), להוסיף שוליים לבנים, או להשלים את הקווים בשוליים עם AI (צריך מפתח OpenAI או Gemini).
* **תמונות:** כל תמונה הופכת לדף.
* **‎.colorbook:** קובץ חוברת מוכן, נפתח מוכן לצביעה.
* אחרי כל הוספה נשאלת שאלה אם לשתף את החוברת ועם מי.

### יצירת חוברות משלך

במדף של "החוברות האישיות שלי" יש כפתור "✨ צור חוברת צביעה":

* **דף אחד:** רעיון בטקסט, ובחירה לאיזו חוברת להוסיף.
* **חוברת שלמה מנושא:** משפט אחד, למשל "פירות הדר בתפקיד שוליית המכשף". קודם מופיעה רשימת שמות לעמודים לאישור ועריכה, ורק אחר כך הציורים.
* **"הפתע אותי":** רעיון אקראי ממאגר מקומי, עובד גם בלי אינטרנט.
* רמת קושי, מספר צבעים, וסגנון ציור (אלגנטי, מבוגר, אגדה, ילדותי, בוטני, מנדלה, ארט נובו, וינטג׳, ויטראז׳, עממי).
* **"🎨 מי מצייר את הדפים":**
  * **ציור מובנה:** מנדלות, גני פרחים וויטראז׳. עובד בלי אינטרנט ובלי שום חשבון. ברירת המחדל מחוץ ל-claude.ai.
  * **קלוד דרך claude.ai:** בתוך ה-Artifact בלבד.
  * **קלוד עם מפתח משלך:** מפתח Anthropic (https://console.anthropic.com). נשמר רק במכשיר.
  * **OpenAI** או **Gemini:** עם המפתח שלך.
* כל דף שנוצר מקבל קווים נקיים, אזורים סגורים, מספור, מקרא ופתרון אוטומטי.
* לחוברת שנוצרת יש כריכת עור עם הטבעת זהב בצבע שבחרת, מנגינה משלה, ועמוד "כל הכבוד" לצביעה בסוף.

### חברות, קבוצות ושיתוף

* חשבון עם מייל, שם משתמש, סיסמה ושאלת אבטחה, או כניסה עם גוגל.
* נעילה בטביעת אצבע (במכשיר בלבד).
* חברות: חיפוש לפי שם משתמש, בקשה ואישור.
* קבוצות: צ'אט בזמן אמת, קישור הזמנה (בתוקף 14 יום), הוספת חברות, יציאה ומחיקה.
* שיתוף חוברת עם חברה או עם קבוצה. מי שמקבלת רואה אותה ב"שותפו איתי" ומוסיפה לספרייה שלה בלחיצה.
* שיתוף כקובץ: PDF להדפסה או ‎.colorbook, דרך וואטסאפ, מייל או Drive.

כדי שהחלק הזה יעבוד צריך לחבר את Supabase פעם אחת. ההוראות בקובץ "הוראות-חיבור-חשבונות-וקבוצות.pdf".

### מוזיקה וצלילים

* נגן קטן בפינה: הפעלה, השתקה, הבא, ווליום.
* שלושה ערוצים ("ריכוז", "אגדה קסומה", "חוברת צביעה"), 10 קטעים בכל אחד, מנוגנים בקוד, ללא תמלוגים.
* אפשר להוסיף שירים מהמכשיר לכל ערוץ.
* צלילי דפדוף: הקלטות אמיתיות של דפי ספר (Kenney, ‏CC0), או הקלטה משלך.
* המוזיקה מתחילה רק אחרי לחיצה ראשונה, וזוכרת את הבחירה האחרונה.

### הגדרות

עיצוב (כולל ערכה מגלגל צבעים ורקע משילוב צבעים), 12 לוגואים, 16 גופני כותרות, כתב לשם האפליקציה ולשמות החוברות, סוג המשפט היומי, צלילי דפדוף וניצוצות, כלי הצביעה שבתפריט, מיקום הסרגל, צד הפינות המעוגלות, כיוון דפדוף, גיבוי ושחזור, קרדיטים, להתקנה, ו"חזרה לברירת המחדל".

## 5. בנייה ופרסום מהקוד (בלי קלוד)

צריך מחשב עם Node.js 20 ומעלה ו-git.

```bash
git clone https://github.com/miriamvoronov-spec/coloring-book.git
cd coloring-book
npm install
npm run dev
npm test
npm run build
npm run build:artifact
```

`npm run dev` מריץ את האפליקציה מקומית לבדיקה, `npm test` מריץ את הבדיקות, `npm run build` בונה את גרסת ההתקנה בתיקייה `dist/`, ו-`npm run build:artifact` בונה קובץ HTML אחד בתיקייה `dist-artifact/`.

### חיבור החשבונות בבנייה

יוצרים קובץ `.env.local` בתיקיית הקוד:

```
VITE_SUPABASE_URL=https://yeapzbqwncxmpkucafli.supabase.co
VITE_SUPABASE_KEY=...
```

במקום `...` מדביקים את המפתח anon public או Publishable.

בלי הקובץ הזה, האפליקציה מבקשת את שני הקודים בטופס במסך "חברות וקבוצות", והם נשמרים במכשיר.

### פרסום שלושת העותקים

```bash
VITE_SAMPLES_PRIVATE='[...]' GHP_WORKTREE=../ghp scripts/release.sh "message"
```

`VITE_SAMPLES_PRIVATE` היא רשימת החוברות הפרטיות שנכנסות רק לעותק שלך, ו-`message` הוא תיאור קצר של השינוי.

הסקריפט בונה את העותק לחברות (`dist-friends/`), את העותק הפרטי (`dist-artifact/`) ואת גרסת ההתקנה, ודוחף את גרסת ההתקנה לענף `gh-pages`. הוא נעצר אם העותק לחברות או גרסת ההתקנה מכילים את החוברת שקנית.

את שני ה-Artifacts מעדכנים ב-claude.ai: העותק הפרטי מ-`dist-artifact/index.html`, והעותק לחברות מ-`dist-friends/miriam-coloring-books.html`.

### כלי העיבוד לחוברות PDF

נמצא ב-`tools/enhance/`, בפייתון:

```bash
cd tools/enhance
pip install -r requirements.txt
python enhance.py ./books --out ./output
```

לכל חוברת הוא כותב SVG ו-PNG לכל דף, PDF נקי להדפסה, קובץ ‎.colorbook מוכן לייבוא, ודוח איכות HTML עם לפני ואחרי. התיקיות `books/` ו-`output/` לא עולות ל-GitHub.

## 6. מבנה הקוד

* `src/app/`: נתונים, IndexedDB, ייבוא, יצירה (creator.ts, procedural.ts), חשבונות (cloud.ts), טביעת אצבע (biolock.ts)

* `src/layers/`: שכבות
* `src/ui/`: לוגואים, כריכות, ארון קסום (cabinet.ts), ניצוצות, צלילים, חלון היצירה (ideas.ts)
* `src/music/`: מוזיקה
* `supabase/`: בסיס הנתונים והוראות החיבור
* `tools/enhance/`: עיבוד חוברות PDF
* `tests/`: בדיקות
* `CLAUDE.md`: ההנחיות וכל ההחלטות שהתקבלו, עם תאריכים

## 7. מה עוד פתוח

* **חשבונות:** הקוד מוכן ונבדק. מחכה למפתח anon public או Publishable מ-Supabase, להרצת `supabase-schema.sql`, להגדרת Site URL, ולחיבור גוגל (לפי ההוראות).
* **הוספת חוברת דף אחרי דף**, ו"הגדרות חוברת" לשיוך פתרון לכל דף.
